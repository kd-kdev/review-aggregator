# SteamReviews+

**Game review keyword analysis web application**

**Work in Progress — Portfolio Project**

SteamReviews+ is an actively developed web application that ingests and analyzes user reviews from Steam to extract meaningful keywords, trends, and insights.

The primary goal of the project is to enable **players** to perform more in-depth research before purchasing a game. By analyzing the frequency and presence of specific keywords across user reviews, players can quickly identify recurring themes such as performance issues, gameplay mechanics, or overall sentiment that may not be obvious from aggregate review scores alone.

At the same time, **game developers** can use the platform to gain structured insight into player feedback. By aggregating and analyzing large volumes of reviews, SteamReviews+ helps highlight commonly mentioned features, pain points, and missing functionality, making it easier to understand how players perceive different aspects of a game.

Overall, SteamReviews+ aims to transform unstructured review text into actionable signals by surfacing recurring keywords, themes, and trends that reflect player sentiment and real-world usage experiences.

UI/UX polish and several planned features are still in progress, with the current focus placed on backend architecture, data processing, and analysis capabilities.

---

## Tech Stack

- **Backend:** Python (Flask)
- **Frontend:** Vue.js (work in progress)
- **Database:** PostgreSQL
- **DevOps:** Docker, Docker Compose
